# Проект transaction analysis app

## Описание:
Приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, 
а также предоставляет другие сервисы.

### Основные модули 

* Модуль в корне проекта *main.py* запустив который, можно получить результат всех реализованных 
в проекте функциональностей

В директории **src** создаются модули с добавлением новых функций

* Модуль **views** 

1. Главная функция *main_views*, которая собирает все данные в единый JSON-ответ

* Модуль **utils** содержит вспомогательные функции, которые используются другими
модулями:

1. Функция *get_greeting* отвечает за вывод приветствия в зависимости от времени суток.
2. Функция *load_data_from_file* считывает данные (Excel) для последующей передачи 
их в основную функцию
3. Функция *filter_data_by_month_range* фильтрует данные с начала месяца входящей 
даты по саму дату
4. Функция *get_card_statistics* по каждой карте выдает последние 4 цифры, 
общую сумма расходов, кешбэк
5. Функция *get_top_transactions* выдает топ-5 транзакций по сумме платежа
6. Функция *get_market_data* выдает данные о валютах и ценах на акции

* Модуль **services**

1. Функция *analyze_cashback_categories* анализирует выгоду по категориям кешбэка 
за определенный месяц и год

* Модуль **reports**

1. Декоратор *report_to_file* для функции-отчета записывает в файл результат, 
который возвращает функция, формирующая отчет
2. Функция *spending_by_category* возвращает траты по заданной категории за последние три месяца 
(от переданной даты)

## Установка

1. Клонируйте репозиторий:

`git clone git@github.com:SlavaMuzhev/transaction_analusis_app.git`

2. Перейдите в папку проекта:

`cd C:\Users\........\transaction_analusis_app>`

3. Установка зависимостей:

`pip install -r requirements.txt`

## Зависимости
* Python 3.x
* Библиотеки, которые указаны в requirements.txt

## Тестирование
Для тестирования используется библиотека **pytest**

Тестами покрываются все функции, находящиеся в модулях из пакета src

Установка pytest:

`poetry add --group dev pytest`

Запуск pytest удобнее всего производить из PyCharm. 
Для этого выполните следующие шаги:
1. Откройте окно Edit Configurations
2. Нажмите на "+" для создания новой конфигурации и выберите pytest
3. Укажите директорию с тестами и директорию проекта в целом

В pytest для анализа покрытия кода надо поставить библиотеку 
**pytest-cov**

Через poetry с добавлением в отдельную группу:

`poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:

`pytest --cov`  — при активированном виртуальном окружении.
